# Flowbase Workspace Theme

## Intent

Flowbase should feel fresh, focused, and quietly optimistic. It is a productivity workspace, not a muted paper notebook or a noisy neon dashboard.

## Color palette

- App canvas: `#F5F9FF`
- Elevated surface: `#FFFFFF`
- Ink: `#1D2635`
- Supporting text: `#6A7484`
- Primary action: `#146CF5`
- Primary soft surface: `#E4EFFF`
- Borders: `#DFE8F6`
- Icon accents: blue `#146CF5`, violet `#7443E5`, seafoam `#00A682`, amber `#F08725`, rose `#D94E83`, cyan `#008FBD`

Dark mode keeps the same hierarchy with canvas `#111721`, elevated surface `#181F2A`, ink `#F6F8FC`, and the same recognizable accent hues.

## Typography and spacing

- Use the system sans stack with tight display tracking for page titles.
- Sidebar group labels: 9px uppercase, 0.16em tracking.
- Sidebar links: 12px medium weight with compact 32px rows.
- Page headings: 30-36px semibold. Body text: 13-14px with relaxed 1.5-1.7 line height.
- Use an 8px spacing rhythm. Standard cards use 16px radius; controls use 8-12px radius.

## Interaction and components

- Use brighter, softly tinted icon backgrounds to give each work mode an immediate visual identity.
- Selected navigation uses a pale primary fill and clear text contrast.
- Hover movement is subtle: 1-2px lift only for actionable cards and buttons.
- Shadows are blue-gray tinted and low opacity. Avoid pure black shadows and heavy glass effects.
- Keep the sidebar compact, group related navigation, and always support keyboard focus plus icon-only labels when collapsed.
